Lighter orchestrators than Kubeflow

Full Kubeflow installs Istio, Knative, and Cert-Manager. Smaller platform teams often pick focused alternatives.

Flyte

Strongly-typed Python workflows with task caching, dynamic fan-out, and cleaner Kubernetes CRD footprint.

Metaflow

Decorator-based Python pipelines that scale to Kubernetes or AWS Batch without YAML manifests.

ZenML

Minimal orchestrator abstraction layer connecting local runs, Airflow, GitHub Actions, or Vertex AI.

ClearML

Agent-based GPU queue and experiment tracker that installs on bare metal or Kubernetes in minutes.
