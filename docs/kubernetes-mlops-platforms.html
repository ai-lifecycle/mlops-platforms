Training orchestration vs. inference CRDs

Running ML workloads on Kubernetes requires clean separation between batch training pipelines and low-latency online serving:

  • Kubeflow (CNCF): Provides Kubeflow Pipelines, Training Operator (PyTorch/MPI), Katib hyperparameter tuning, and KServe integration.
  • Flyte: Strongly-typed Python workflows with immutable container execution, intra-task caching, and dynamic fan-out on Kubernetes.
  • KServe & Seldon Core: Dedicated Kubernetes Custom Resource Definitions for serverless scale-to-zero, canary rollouts, and GPU vLLM serving.
  • Ray (KubeRay): Distributed Python actor clusters for multi-node LLM pre-training, fine-tuning, and Ray Serve autoscaling.
